# Lumen

Welcome to the documentation for **Lumen**, an AI model gateway for research institutions.

Lumen sits in front of many different AI models — hosted on different servers and platforms across your institution — and gives you a single, unified way to reach all of them through a browser chat interface or a common API.

Start with the [Introduction](introduction.md) to learn what Lumen is, then browse the guides for [users](guides/chat.md), [admins](admin/config.md), and [developers](architecture.md).
